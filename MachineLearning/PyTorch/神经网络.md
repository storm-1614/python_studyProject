# 神经网络

神经网络定义了张量的流动路径（前向），损失函数提供了反向传播的起点（误差），Autograd 自动把误差转换为梯度（信号），优化器消费梯度去更新网络内部的张量（参数），这便是 PyTorch 深度学习的全部。  

PyTorch 提供了 `nn.Module` 这个强大基类来作为神经网络模型的标准蓝图。  a


## 定义模型

构建 `nn.Module` 按如下来：
- 创建一个继承自 `torch.nn.Module` 的类
- 在类的构造函数 `__init__` 中，定义模型所需要的所有“层”
- 在 `forward` 方法中，定义数据从输入到输出的完整计算路径，即前向传播逻辑  

``` python
from torch import nn

class LinearRegressModel(nn.Module):
    def __init__(self):
        super().__init__()
        # 定义一个线性层 nn.Linear(in_features, out_features)
        # in_features=1: 输入的特征维度为 1
        # out_features=1: 输出的特征维度为 1
        self.linear_layer = nn.Linear(in_features=1, out_features=1)

    def forward(self, x):
        # 定义前向传播路径
        # 直接调用我们定义的层即可
        return self.linear_layer(x)
    
model = LinearRegressModel()
print(model)

for name, param in model.named_parameters():
    print(f"参数名称：{name}, 参数值：{param.data}")
```

输出：

```
LinearRegressModel(
  (linear_layer): Linear(in_features=1, out_features=1, bias=True)
)
参数名称：linear_layer.weight, 参数值：tensor([[0.6943]])
参数名称：linear_layer.bias, 参数值：tensor([-0.4358])
```

PyTorch 的 `nn.Linear` 在创建时会自动随机初始化权重(weight) 和偏置(bias)。  
1. 权重默认使用 Kaiming 均匀分布进行初始化，这是一种针对 ReLU 激活函数优化的初始化方法，使得每层输出的方差保持一致，有助于梯度在反向传播时稳定流动。  
2. 偏置默认使用均匀分布，范围由权重的 fan-in 决定。  

## 损失函数
模型需要一把标尺来衡量它预测的好坏，也就是损失函数（有时也叫目标函数或者是代价函数）  
它接收模型的预测值和数据的真实标签作为输入，输出一个标量值（损失值），该值量化了两者之间的差距。  
损失值越大，代码模型预测得越差，损失值越小，代表预测得越好。整个训练过程的目标，就是通过调整模型参数，使得这个损失值尽可能小。 PyTorch 在 `torch.nn` 中提供了各种预置的损失函数，比如：  
- **均方误差损失**：
    $MSE = \frac{1}{n} \sum^{n}_{i=1}(y_i - \^{y}_i)^2$
    常用于回归任务，计算的是预测值与真实值之差的平方的平均值，对应类是 `nn.MSELoss`。因为误差损失被平方了，所以一旦出现较大的单次预测偏差，会导致最终的 MSE 值急剧增加。  
- **交叉熵损失**：
    常用于分类任务，它是衡量模型预测的类别概率分布于真实类别分布之间的差距，对应的类是：`nn.CrossEntropyLoss`  

对于上面的线性回归任务，使用 `nn.MSELoss`：
``` python
from torch import nn
import torch

# 实例化一个损失函数

loss_fn = nn.MSELoss()

# 假设模型预测值为 y_pred，真实标签为 y_true
y_pred = torch.tensor([2.5])
y_true = torch.tensor([2.0])

# 计算损失
loss = loss_fn(y_pred, y_true)
print(f"损失值: {loss.item():.4f}") # (2.5 - 2.0)^2 = 0.25
```

输出结果：
```
损失值: 0.2500
```

## 优化器
梯度指示优化方向，还需要一个舵手——优化器来具体执行参数的更新：  

从最开始的：
``` python
w = w - learning_rate * grad
```

更新权重，到现在，引入优化器将这一过程自动化，引入更复杂的更新策略，以实现更快更稳定的收敛。优化器接收模型的所有参数和学习率作为输入，并负责在每次反向传播后更新这些参数。  

PyTorch 在 `torch.optim` 模块中提供了多种优化器：
- **随机梯度下降(SGD)**：最基础的优化器，完全遵循梯度下降到更新规则。  
- **Adam：一种自适应学习率的优化器，为每个参数独立计算学习率，结合了动量和 RMSProp 算法的思想。在绝大多数场景下，Adam 都是一个表现优异且无需过多调参的稳健选择。  

创建一个优化器如下：
``` python
# 实例化一个模型
model = LinearRegressModel()

# 设定学习率
learning_rate = 0.01

# 创建一个 SGD 优化器，将模型的所有参数和学习率传入
optimizer = torch.optim.SGD(params=model.parameters(), lr=learning_rate)
```

优化器 optimizer 接管了 model 的所有参数，不需要手动更新它们，只需要计算完梯度后调用 `optimizer.step()` 即可。  

## 数据
在 PyTorch 中，数据加载器(DataLoader) 和数据管道(Data Pipeline) 是用来高效地加载、预处理、批量化数据，并送入模型训练的核心组件，主要由两部分构成：  
- `torch.utils.data.Dataset`：定义数据从哪来，如何读取单条样本
- `torch.utils.data.DataLoader`：在 Dataset 之上，负责批量化，打乱顺序、多进程并行加载

一个简单的示例：
``` python
from torch.utils.data import Dataset, DataLoader
import torch

# 创建自定义数据集
class ToyDataset(Dataset):
    def __init__(self, num_samples = 100):
        # 创建一些符合 y = 2x + 噪声 的数据
        self.X = torch.randn(num_samples, 1) * 10
        self.y = 2 * self.X + torch.randn(num_samples, 1) * 2 # y = 2x + noise
        self.num_samples = num_samples

    def __len__(self):
        return self.num_samples
    
    def __getitem__(self, idx) :
        return self.X[idx], self.y[idx]


# 实例化数据集
dataset = ToyDataset()

# 创建数据加载器
# batch_size=10: 每个批次包含 10 个样本
# shuffle = True: 在每个 epoch 开始时打乱数据
dataloader = DataLoader(dataset=dataset, batch_size = 10, shuffle = True)

# 我们可以像遍历普通的可迭代对象一样遍历 dataloader
X_batch, Y_batch = next(iter(dataloader))

print(f"一个批次的数据形状: {X_batch.shape}")
print(f"一个批次的标签形状: {Y_batch.shape}")
```


## 标准训练回路
机器学习必要组件：模型、损失函数、优化器和数据加载器。将其组合在一起就是深度学习最核心的流程：标准训练回路：  
- 外层循环(Eposhs)：对整个数据集进行多轮完整的训练，每一轮称为一个周期
- 内层循环(Batches)：在每个周期内，从 DataLoader 中遍历所有的数据批次
- 梯度清零：在计算新一轮梯度之前，必须调用 `optimizer.zero_grad()` 来清除上一轮的旧梯度。  
- 前向传播：将数据批次送入模型，得到预测结果，即`y_pred = model(X_batch)`
- 计算损失：使用损失函数计算预测值与真实标签之间的差距，即 `loss=loss_fn(y_pred, y_batch)`
- 反向传播：在损失张量上调用 `loss.backward()` PyTorch 自动计算模型中所有参数的梯度
- 参数更新：调用 `optimizer.step` ，优化器将根据计算出的梯度来更新模型中的所有参数。
