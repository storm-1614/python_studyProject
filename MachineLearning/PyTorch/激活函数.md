# 激活函数

激活函数的作用是为神经网络引入非线性变换能力。    


## 具体作用
- 引入非线性，提升模型容量
    让网络可以拟合任意复杂的函数
- 控制输出范围
    有些激活函数将输出限制在特定区间（如 Sigmoid 输出 (0, 1)，Tanh 输出 (-1, 1)），有助于将数值稳定在可控范围，或作为门控信号、概率输出等。  
- 提供稀疏性
    例如 ReLU 会将所有负数直接置零，使网络中的神经元只有一部分被激活，这种稀疏性可以带来计算效率、缓解过拟合，也符合生物学神经元的“稀疏编码”特点。
- 缓解梯度消失/爆炸
    早期 Sigmoid/Tanh 在饱和区梯度接近 0，导致深层网络难以训练。ReLU 及其变体在正区间导数为常数，极大缓解了梯度消失，使训练更深的网络成为可能。



## 实际
在构建好数据加载器，把数据送入模型时，模型的每个隐藏层后面会紧跟一个激活函数。这些激活函数的非线性堆叠，让网络从喂进去的原始像素，文本 token 中学到丰富的特征表示。
